## Bundled assets

None. This project ships no third-party models, textures, sounds, fonts or
data. Every car, track, prop and material is generated procedurally in GDScript
at runtime, so there are no external asset licenses to satisfy.

## Engine

Built with Godot Engine (https://godotengine.org), which is licensed under the
MIT License. Godot itself is not redistributed here; the user installs it
separately.

## If you add third-party assets later

MIT code does not make third-party assets MIT. Before publishing commercially,
check the license of every model, texture, font and sound you add. Useful
sources of assets that are safe for commercial use:

- **CC0 / Public Domain**: Kenney (kenney.nl), Poly Haven, ambientCG.
- **CC-BY**: OpenGameArt, Poly Pizza (attribution required).
- **MIT**: many GitHub vehicle-physics and template projects — but note their
  repositories often mix in separately-licensed art. Verify per file.

General rule for this project's own code: MIT lets you reuse and modify it
freely; you must keep the copyright and license notice, but you are not
obliged to publish your source.
